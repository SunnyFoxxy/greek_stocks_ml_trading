# Greek Stocks ML Trading Strategy


This project builds an end-to-end algorithmic trading strategy for the Greek stock market (Euronext Athens). It uses daily price data for the 33 most liquid Greek stocks, technical indicators and European macro data (ECB interest rates, Greek government bond spread) to predict if a stock will grow over the next 30 trading days. The predictions are used to simulate a trading strategy, and its results are compared with simply holding the Athens stock market index.
